# 眠记 v1.1.0

## 睡后补记与分析

- 不再要求估计精确的入睡分钟数；可在醒后选择大致入睡区间与夜间醒来情况，也可以选择“记不清”或暂不填写。
- 历史页提供最近 7 天/30 天的本地趋势和标有样本数的证据式提示；记录时长不是实际睡着的时长，提示不构成医学诊断。
- 旧记录的估计入睡时间保持原样；JSON 备份兼容旧格式，CSV 新增入睡区间和夜醒情况列，空值不会被臆测补齐。

## 安装与数据保护

请直接**覆盖安装**旧版，不要卸载或清除应用数据。若提示签名不一致，请停止安装并反馈。安装后请检查旧记录仍在，尝试一条新补记并重新打开应用，再分别导出 JSON 和 CSV 检查内容。

## 验证边界

自动测试与 APK 构建不能替代在用户手机上覆盖升级、检查历史数据以及实际使用系统文件保存窗口。未完成这些步骤时，不应宣称真机验收完成。
