# 眠记 v1.0.8

## 修复

- Android 升级后旧网页离线缓存仍加载 v1.0.6 的错误脚本，导致白屏：原生启动时退出旧 Service Worker，仅移除 Workbox 页面缓存；Android 版不再注册网页离线缓存。
- 数据库打开失败/等待过久时显示安全提示，不再静默切换到空数据库；网页重载时复用已打开的原生连接。
- JSON 完整备份、CSV 表格改用系统“保存文件”窗口；写入并关闭文件成功后才提示成功。取消、写入失败均不更新成功备份时间，不再退回不可靠的网页下载。
- 导出实时读取数据库，避免漏掉设置页打开后新增的记录。
- 原生数据库操作按顺序执行，防止快速重复操作产生两条进行中的记录或串用事务。
- 补齐通知计时的开始时间；版本显示和更新检查统一读取应用版本。

## 验证与边界

- 单元/组件回归测试、页面流程测试、网页与 Android 资源构建检查。
- 用真实 v1.0.6 / v1.0.7 APK 资源复现“升级后仍白屏”，验证恢复后旧 IndexedDB 测试记录和设置仍保留；另加入自动化缓存升级回归测试。
- 已完成独立代码审查。模拟器测试环境不稳定，**本版未完成 Android 系统保存窗口的端到端验收，也尚未在用户的 vivo 手机上实测**；不把构建成功等同于真机验证。
- 未改数据库结构、原始记录时间或签名配置。以前因异常回退而存入 IndexedDB 的记录仍保留，但本版不自动将它们合并到 SQLite。

## 安装与快速验收

1. 下载本页 APK，直接覆盖安装；**不要先卸载，不要清除应用数据**。如系统提示签名冲突，请停止安装并反馈，不要为安装而删除旧应用。
2. 打开“历史”确认原有记录仍在；关闭后再次打开确认正常。
3. 设置 → 导出完整备份 / 导出表格 → 选择保存位置 → 保存。确认能找到文件；取消操作不应显示保存成功。
4. 如果仍无法打开，反馈手机型号、Android 版本和屏幕表现，保留原应用数据。

旧版本 Release 和原 APK 保留，可用于问题对比；不建议自行降级或卸载。
