# 眠记 (Mianji Sleep) - 隐私哲学与多端存储架构说明

> 原生 APP 方案已暂停，本文件中的原生内容仅保留为历史设计，不代表当前交付能力。

---

## 1. 隐私哲学与数据所有权

- **本地优先 (Local-First)**：
  “眠记”的诞生宗旨是为用户提供纯净、无打扰且尊重睡眠隐私的记录工具。用户的睡眠就寝时间、起床时间、午睡习惯属于敏感的个人生物节律数据。
- **睡眠数据本地优先，无行为追踪**：
  应用不设用户登录体系，无远程睡眠数据库，无 Google Analytics、友盟等第三方广告与埋点 SDK。睡眠记录只保存在本机，不会自动上传；仅当用户主动提交意见时，反馈正文、选填联系方式和提交时间会发送至第三方邮件转发服务，且不会附带睡眠记录。
- **完全的数据掌控力**：
  用户随时可以通过标准 JSON 格式将全部数据完整导出，不绑定任何特定专有云端服务。

## 2. 网页端 (PWA) 与原生 APP (Android/iOS) 存储对比

| 维度 | 网页离线版 (PWA) | 原生 APP (Android / iOS) |
| :--- | :--- | :--- |
| **底层存储介质** | 浏览器内置 IndexedDB | 原生私有 SQLite 关系数据库 |
| **持久化生命周期** | 受浏览器缓存清理政策约束 | 系统级私有应用沙箱，常驻硬盘 |
| **误清理风险** | 浏览器清理历史或空间极低时可能被清理 | 仅系统重置或主动“卸载应用”时删除 |
| **自动备份能力** | 取决于浏览器文件夹授权能力；多数手机浏览器不可用，此时需手动导出 JSON | 原生级文件沙箱与共享（历史设计，当前不交付） |
| **桌面小组件** | 不支持 | 支持 Android AppWidget 实时状态展示 |

## 3. JSON 备份格式标准与恢复机制

眠记的备份文件采用标准 UTF-8 编码的 JSON 格式，结构如下：

```json
{
  "version": 1,
  "exportedAt": "2026-09-03T16:00:00.000Z",
  "segments": [
    {
      "id": "7b0b2e8d-5654-4696-851f-614f04c6e93c",
      "kind": "night",
      "groupId": null,
      "startAt": "2026-09-02T15:30:00.000Z",
      "startTimezone": "Asia/Shanghai",
      "endAt": "2026-09-02T23:00:00.000Z",
      "endTimezone": "Asia/Shanghai",
      "status": "completed",
      "uncertainReason": null,
      "createdAt": "2026-09-02T15:30:00.000Z",
      "updatedAt": "2026-09-02T23:00:00.000Z",
      "finishedAt": "2026-09-02T23:00:00.000Z",
      "schemaVersion": 1
    }
  ]
}
```

### 字段说明：
- `id`: 睡眠记录唯一 UUID；
- `kind`: `night`（夜间睡眠）或 `nap`（日间午睡）；
- `startAt` / `endAt`: ISO 8601 标准 UTC 时间戳；
- `startTimezone` / `endTimezone`: 记录所在时区（如 `Asia/Shanghai`），保证跨时区出差时睡眠时段换算绝对精确；
- `status`: `active`（进行中）、`completed`（已正常完成）、`uncertain`（标记为存疑）或 `invalid`；
- `groupId`: 用于关联当日接续睡眠（例如误起撤销或再睡一段）的多段记录组合。

### 恢复与冲突消解：
导入备份文件时，系统会在应用内逐条比对本地与备份中的记录：
1. **无冲突记录**：自动合并；
2. **同 ID 记录内容差异**：提供逐条对比弹窗，用户可显式选择“保留当前”或“采用备份”，绝不静默覆盖。
