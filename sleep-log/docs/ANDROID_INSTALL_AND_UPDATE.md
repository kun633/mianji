# 眠记 (Mianji Sleep) - Android 安装、更新与数据保护指南

> 原生 APP 方案已暂停，本文件仅保留为历史设计，不代表当前交付能力；当前请使用网页版/PWA。

本文档为“眠记” Android 原生安装包（APK）的使用、覆盖更新及数据防丢失指南。

---

## 1. 首次安装指南（Debug / Release APK）

1. **下载安装包**：获取最新的 `mianji-sleep.apk` 或 `app-debug.apk`。
2. **系统安全提示处理**：
   - 国内主流手机（华为、小米、OPPO、vivo 等）在安装未上架应用商店的 APK 时，会弹出“未知应用安装”、“风险应用提示”或“未通过安全检测”。
   - **此为正常系统机制**：眠记为开源无网络上报的纯本地应用，不索取定位、通讯录或相机等敏感权限。
   - 在弹窗中选择“**允许来自此来源的应用安装**”或点击“**继续安装 / 忽略风险**”即可完成。

---

## 2. 覆盖更新规则（严禁卸载）

### 核心原则：**直接覆盖安装，绝不要先卸载！**

- **为什么可以覆盖更新？**
  Android 系统机制规定：相同应用 ID (`com.mianji.sleep`) 且采用**相同签名证书**编译的 APK，安装时会自动触发系统的**覆盖安装 (In-Place Update)**。
- **覆盖安装对数据的影响**：
  - 应用的私有内部存储（`/data/data/com.mianji.sleep/databases/` 下的 SQLite 睡眠数据库、小组件配置与应用设置）将**100% 完整保留**。
  - 新版本直接读取原有记录，无需手动重新导入。
- **危险红线：严禁“先卸载、再安装”**：
  - 如果用户在系统桌面长按并点击“卸载”，Android 系统会立即将该应用的私有数据目录彻底抹除！
  - 一旦误卸载且没有导出备份，数据将无法追回。

---

## 3. 换机与版本迁移：JSON 备份安全底线

为了应对手机损坏、更换新手机或跨大版本升级的突发情况，请养成以下习惯：

1. **重大升级前手动备份**：
   - 打开“设置”页面 -> 点击“**导出完整备份 (JSON)**”。
   - 将生成的 `眠记-备份-YYYY-MM-DD.json` 文件发送到微信文件传输助手、QQ 收藏或网盘。
2. **在新设备或新环境中恢复**：
   - 安装好新应用后，打开“设置” -> 在“恢复备份”中选择导出的 `.json` 文件。
   - 系统将自动解析历史记录并无损导入，原有时区与时间点完整还原。
