# 眠记 (Mianji Sleep Log)

面向手机日常使用的可信睡眠记录 PWA。在事件发生时快速记录、保存准确时间点，支持多段夜间睡眠、午睡、离线运行与本地安全备份。

---

## 1. 快速开始

### 安装依赖
```bash
npm install
```

### 本地开发
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173`。

### 运行测试
```bash
npm test          # 运行 Vitest 单元与组件测试
npm run test:e2e  # 运行 Playwright 移动端端到端测试
npm run check     # 运行完整质量核验 (Unit + Build + E2E)
```

### 生产环境构建
```bash
npm run build
```
构建产物将输出至 `dist/` 目录，可直接上传至任意支持 HTTPS 的静态 Web 服务器进行分发托管。

---

## 2. 手机与移动端使用指南

### 添加到手机桌面
1. 使用 Android 手机或 iPhone 的现代浏览器打开线上部署网址（必须为 HTTPS）。
2. 点击浏览器底部或右上角菜单按钮（三条横线或三个点）。
3. 选择 **“添加到桌面”** 或 **“安装应用”**。
4. 返回手机桌面，即可点击“眠记”图标全屏独立运行。

### 离线使用与数据保存
- 应用具备完整 Service Worker 离线缓存能力，首次加载后无需网络连接即可随时打开和记录。
- 所有睡眠记录默认保存在手机本地浏览器的 **IndexedDB** 数据库中，不会自动上传至远端服务器。
- 进行中的睡眠记录不依赖后台计时器，手机锁屏、重启或网页关闭均不会丢失准确开始时间。

## 3. 重要数据保护与备份恢复

> **注意：** 手机浏览器在清理网站缓存或卸载应用时可能删除 IndexedDB 本地数据。请务必配合以下措施：

### 手机文件夹自动备份
此能力取决于浏览器是否支持文件夹授权；多数手机浏览器不支持时，页面不会显示该模块，请使用 JSON 手动导出。

1. 在支持该能力的浏览器中，于“设置”页面点击 **“选择自动备份文件夹”**。
2. 授权手机上的本地文件夹（如 `Download` 或专门的备份目录）。
3. 授权后，每次新增、结束、删除记录或修改类型，应用都会自动将最新全量数据写入该文件夹下的 `眠记-自动备份.json` 文件。
4. 该独立文件存储在手机文件系统中，不会随浏览器数据清理而丢失。

### 手动备份与恢复
- **手动导出**：在“设置”页随时点击“导出完整备份 (JSON)”或“导出表格 (CSV)”。
- **备份恢复**：在“设置”页选择备份 JSON 文件，系统会自动校验格式、预览记录条数与日期范围，并在合并冲突时提供保留当前或采用备份的明确选择。

---

## 4. 隐私与安全声明

- **睡眠数据本地保存**：睡眠记录只保存在本机，不会自动上传；仅当用户主动提交意见时，反馈正文、选填联系方式和提交时间会发送至第三方邮件转发服务。
- **无账户与追踪**：本项目无用户账户、无广告或行为追踪器。
- **构建包安全**：`dist/` 仅包含应用静态前端代码与资源，不包含任何用户个人睡眠数据。
